# Vectoora 🎨

**Vectoora** is a desktop vector graphics and stencil design application built with Python, PyQt6, and OpenCV. It transforms live camera feeds and raster images into clean, editable vector line art.

## ✨ Features
- **Live Camera Stencil:** Real-time edge detection and morphological thinning to generate clean vector strokes from webcam input.
- **Vector Editing Suite:** Pen tool, shape drawing, and precision lasso/object erasing.
- **Manufacturing & Laser Ready:** Built-in loop continuity scanner and auto-sealing for print, vinyl, and laser cutting.
- **Multi-layer & Undo/Redo:** Full layer visibility controls and complete action history stack.
